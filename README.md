# UnvibeCode Engineering Challenge 2026 — Cohort 3

My technical exploration and participation in the UnvibeCode Engineering Challenge 2026.

This repository documents my day-by-day progress, experiments, technical investigations, product observations and learnings across both challenge tracks.

## Challenge Objectives

- Understand the UnvibeCode product, architecture and technology stack.
- Run and explore UnvibeCode locally.
- Investigate a real technical issue and establish reproducible evidence.
- Explore developer workflows and identify opportunities to improve adoption and repeat usage.
- Develop practical technical and product-thinking skills.

## Tracks

### Track 1 — Engineering Issue Investigation
Investigate UnvibeCode using real repositories, identify a meaningful technical issue, reproduce it and document evidence for a GitHub issue.

### Track 2 — Developer Adoption & Repeat Usage
Explore how UnvibeCode can become a more accessible and useful part of everyday developer workflows through a focused product proposal.

## Repository Structure

- `progress/` — Daily progress and learning logs.
- `research/` — Product, architecture and technology research.
- `track-1-engineering-investigation/` — Technical investigation and evidence.
- `track-2-developer-adoption/` — Developer journey, friction points and proposal.

## Approach

Understand first. Experiment next. Verify every finding. Document the reasoning and evidence.
